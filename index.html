Support

Run your first project

Open the Harbor notebook example, select main.py and press Run. Edit a value in readings.py and run main.py again to see the result. Open the Guide inside the app to look up supported modules.

Find or back up your files

Open Apple's Files app and look under On My iPhone or On My iPad, then ScriptCove and Projects. Copy a project folder to a location of your choice before removing the app. Reopen the project after editing files externally.

Why does an import fail?

The app includes a local Python interpreter and a selection of standard library modules. Desktop GUI toolkits and separately compiled third-party packages are outside its supported environment. Check the module name and the guide, or include your own source module alongside the script.
